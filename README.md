# Hospital Management System

A premium, full-stack hospital management system designed for clinical excellence. Features include attendance tracking and overtime management for employees.

## 🚀 Tech Stack
- **Frontend**: React 19, TypeScript, Vite, Vanilla CSS (Premium Aesthetics)
- **Backend**: Node.js, Express, MongoDB (Mongoose)
- **Authentication**: JWT, BCrypt

## 📁 Project Structure
- `src/`: Frontend React source code.
  - `components/Login/`: Premium responsive login component.
- `server/`: Backend Node.js server.
  - `index.js`: Server entry point.
  - `.env`: Environment variables configuration.

## 🛠️ Setup Instructions

### 1. Backend Setup
1. Open a terminal in the `server` directory.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Configure your MongoDB connection in `.env`.
4. Run the server:
   ```bash
   npm run dev
   ```

### 2. Frontend Setup
1. Open a terminal in the root directory.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
